# 非機能要件: パフォーマンス・セキュリティ・可用性

## 7. 非機能要件

ローカルで動作するデスクトップアプリのプラグインであり、サーバー・ネットワーク要件は存在しない。

### パフォーマンス

| 指標                       | 目標値                       | 計測方法       |
| -------------------------- | ---------------------------- | -------------- |
| Inkdrop 起動時間への影響   | 体感で分からない程度         | 手動での動作確認 |
| コマンド実行から反映まで   | 即時（1フレーム相当）        | 手動での動作確認 |
| 常駐処理                   | なし（イベント駆動のみ）     | 実装レビュー   |

- ポーリングやタイマーを持たず、コマンド実行時と `activate()` 時のみ処理が走る

### セキュリティ

- 認証・認可: 不要（ローカル動作のみ、ユーザー権限で完結）
- データ暗号化: 不要（保持するのは透過度の数値のみ）
- 入力バリデーション: 設定スキーマの `type` / `minimum` / `maximum` で Inkdrop 側に委譲する
- 機密情報の扱い: ノート本文を含むユーザーデータには一切アクセスしない
- ネットワーク通信: 行わない
- 依存パッケージ: 追加しない（サプライチェーンリスクを持ち込まない）

### 可用性・運用

- 障害の影響範囲: 最大でも「背景の見た目が意図と異なる」に留まり、ノートデータには影響しない
- 復旧手段: プラグインを無効化すると `deactivate()` がスタイルシートを外し、Inkdrop 既定の見た目に戻る
- バックアップ: 不要（永続データを持たない）
- 監視・アラート: なし
- ロールバック手順: ipm で以前のバージョンを再インストールする
- 互換性: `package.json` の `engines.inkdrop` で対応バージョンを宣言する。
  v2 以降は Inkdrop 6 専用（`^6.0.0`）。v4 / v5 利用者には 1.2.x が配信され続ける
- 本体更新への追従: Inkdrop 本体が背景色変数名や既定の不透明度を変更すると、
  見た目が意図とずれる。症状はスタイルが当たらない／既定と一致しないだけでデータには影響しないが、
  本体のメジャー更新時は `docs/design/detailed-design.md` の既定値表と実装の突き合わせが必要
