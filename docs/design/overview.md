# 概要: 背景・目的・スコープ

## 1. 背景と課題

### 現状

Inkdrop はノートアプリとして常時起動したまま他アプリと併用されることが多いが、
本体の設定にウィンドウの透過度を変更する項目が存在しない。

### 課題・ペイン

- 課題1: 背後のウィンドウ（ブラウザ・ターミナル等）を参照しながらノートを書けない
- 課題2: 透過度は作業内容によって変えたくなるため、固定値ではなく都度切り替えたい

### 解決しない場合の影響

ウィンドウの切り替え操作が頻発し、参照しながらの執筆効率が下がる。

---

## 2. 目的とゴール

### 目的

Inkdrop のウィンドウ透過度をユーザーが設定でき、任意のタイミングで有効化／無効化できるようにする。

### 成功指標

| 指標                     | 現状値 | 目標値                     | 計測方法       |
| ------------------------ | ------ | -------------------------- | -------------- |
| 透過度の変更手段         | なし   | 設定画面から数値で指定可能 | 手動での動作確認 |
| 有効化／無効化の操作手段 | なし   | キーマップ・メニュー・コマンド | 手動での動作確認 |

### スコープ外

- スコープ外1: ウィンドウごと（メインウィンドウ以外）に異なる透過度を設定すること
- スコープ外2: エディタ領域のみ・サイドバーのみといった部分的な透過
- スコープ外3: 透過度の状態をセッションをまたいで永続化すること（設定値のみ永続化する）

---

## 3. スコープ

### 対象ユーザー

- プライマリ: Inkdrop を他アプリと並べて常時表示しているユーザー
- セカンダリ: デスクトップの見た目をカスタマイズしたいユーザー

### 機能一覧

| 優先度 | 機能                   | 説明                                                             |
| ------ | ---------------------- | ---------------------------------------------------------------- |
| Must   | 透過度の設定           | プラグイン設定で 40〜100 の数値を指定する                        |
| Must   | 透過の有効化           | `transparency:active` で設定値をウィンドウに適用する             |
| Must   | 透過の無効化           | `transparency:deactive` で不透明（1.0）に戻す                    |
| Should | キーマップ・メニュー   | `cmd-t` / `alt-cmd-t` と Plugins メニューから操作する            |
| Should | 起動時の自動適用       | メインウィンドウの起動時に透過を適用する                         |
| Won't  | ウィンドウ別の透過設定 | 複数ウィンドウごとの個別設定は対応しない                         |
