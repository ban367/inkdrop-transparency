# 概要: 背景・目的・スコープ

## 1. 背景と課題

### 現状

Inkdrop はノートアプリとして常時起動したまま他アプリと併用されることが多い。
Inkdrop 6 には acrylic ウィンドウがあり背景は半透明になるが、その度合いは固定で、
本体の設定に調整項目が存在しない。

### 課題・ペイン

- 課題1: 既定の透け具合が作業内容や壁紙に合わず、濃すぎる／薄すぎると感じても変えられない
- 課題2: 領域ごとに求める度合いが異なる（エディタは可読性を優先したいが、サイドバーは透けてよい）
- 課題3: 作業内容によって切り替えたいため、固定ではなく都度の有効化／無効化が要る

### 解決しない場合の影響

ウィンドウの切り替え操作が頻発し、参照しながらの執筆効率が下がる。

---

## 2. 目的とゴール

### 目的

Inkdrop 6 の acrylic ウィンドウの透け具合を、領域ごとにユーザーが調整できるようにする。

### 成功指標

| 指標                     | 現状値       | 目標値                             | 計測方法         |
| ------------------------ | ------------ | ---------------------------------- | ---------------- |
| 調整できる領域           | 0（固定）    | 4領域（サイドバー・一覧・エディタ・メニュー） | 手動での動作確認 |
| 既定値での見た目         | -            | Inkdrop 既定と一致（無害）         | 手動での動作確認 |
| 有効化／無効化の操作手段 | なし         | キーマップ・メニュー・コマンド     | 手動での動作確認 |

### スコープ外

- スコープ外1: ウィンドウごと（メインウィンドウ以外）に異なる設定を持つこと
- スコープ外2: ぼかし（vibrancy）の強さや有無の制御。Inkdrop がウィンドウ生成時に決めており変更できない
- スコープ外3: ウィンドウ全体を半透明にすること。`setOpacity` が Inkdrop 6 に存在しない
- スコープ外4: 適用状態をセッションをまたいで永続化すること（設定値のみ永続化する）

---

## 3. スコープ

### 対象ユーザー

- プライマリ: Inkdrop を他アプリと並べて常時表示しているユーザー
- セカンダリ: デスクトップの見た目をカスタマイズしたいユーザー

### 機能一覧

| 優先度 | 機能                     | 説明                                                                 |
| ------ | ------------------------ | -------------------------------------------------------------------- |
| Must   | 領域ごとの不透明度の設定 | サイドバー・ノート一覧・エディタ・メニューを 0〜200 の倍率で指定する |
| Must   | 適用                     | `transparency:active` で設定値をスタイルシートとして適用する         |
| Must   | 解除                     | `transparency:deactive` で Inkdrop 既定の見た目に戻す                |
| Must   | 既定値の無害性           | 既定（すべて 100）では Inkdrop 既定と見た目が一致する               |
| Should | キーマップ・メニュー     | `ctrl-alt-cmd-t` / `alt-cmd-t` と Plugins メニューから操作する      |
| Should | 起動時の自動適用         | メインウィンドウの起動時に適用する                                   |
| Should | 設定変更の反映           | 設定画面から戻った時点で再適用する                                   |
| Should | 前提条件の通知           | acrylic が無効なときに有効化と再起動を促す                           |
| Won't  | ぼかしの制御             | vibrancy は Inkdrop がウィンドウ生成時に設定しており変更できない     |
| Won't  | ウィンドウ全体の透過     | `setOpacity` が Inkdrop 6 に存在しないため実現できない               |
| Won't  | ウィンドウ別の設定       | 複数ウィンドウごとの個別設定は対応しない                             |
